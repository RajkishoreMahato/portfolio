# Rajkishore Mahato — Portfolio

A responsive, interactive portfolio for Rajkishore Mahato, Product and Business Analyst.

The site is intentionally static: role-fit controls, the theme switch, expandable experience, detail pop-ups, scroll reveals, and the reading-progress bar run in the browser without a server or account. Scroll effects respect the visitor's reduced-motion preference.

## Run locally

Open `index.html` in a browser. The site has no build step or runtime dependencies. The resume download is served from `assets/Rajkishore-Mahato-Resume.pdf`.

## Publish with GitHub Pages

Push the site files to a GitHub repository, then enable GitHub Pages for the branch and folder containing `index.html`.
